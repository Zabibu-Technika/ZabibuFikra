What it is

Middleware for AI that has to survive the device.

Between the application and the local model sits the part that decides whether on-device inference is usable: memory, heat, context length, session recovery, model delivery and engine choice. Fikra Edge Runtime owns that layer.

01

Sessions that survive

History and state are written atomically. An app killed by the OS resumes exactly where it stopped, without re-reading the conversation.

02

Context that compacts

A token budget, a pinned system prompt, merging of old turns and eviction — in that order, on turn boundaries, never mid-answer.

03

Speculation that pays

N-gram drafts verified in one pass. On repetitive work it produces more than one token per weight read; on free-form prose it steps aside.

04

Sampling that composes

Temperature, top-k and top-p with exact rejection sampling, so sampled output and speculative verification work together correctly.

05

Engine agnostic

llama.cpp today, other runtimes tomorrow, behind one stable C ABI. Adapters stay below the line; applications never see them.

06

Distribution built for data cost

Signed manifests, resumable and delta downloads, and local sharing over hotspot or USB. One download, many devices.
