Investor kit

The company and the product.

What we have shipped

  • Fikra Model 2 – 4B — Apache 2.0, 262K context, EN/SW, 91.3% release suite.
  • Fikra Model 1 – 2B — 131K context, Gemma-4-2B-it base, custom license.
  • Weaver — terminal coding agent with onboarding and receipts.
  • Zabibu Arif — multi-axis agent workspace and CLI.
  • Fikra Edge Runtime — commercial deployment layer, pilots.

The model

Open weights create distribution. The commercial runtime, support, and enterprise deployment layer create revenue. The Fikra family is built for private, offline-first work in regulated, low-connectivity, and data-sovereign environments.

Roadmap

  • Edge Runtime commercial pilots and managed deployment.
  • Model family and evaluation suite expansion.
  • Enterprise integrations and developer tooling.
