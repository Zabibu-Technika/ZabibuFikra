What is a GGUF?

It is the model file format used by local AI apps. Think of it as a PDF for an AI model. You do not open it directly; you import it into the app. Keep the .gguf ending and do not unzip it.

The file is large. Use Wi-Fi, keep the screen on, and wait for the download to finish. If it stops, start it again. The model is also on Hugging Face.

Step 3 / prove it

Test that it is really offline.

01

Disconnect

Turn on Airplane Mode on your phone, or turn off Wi-Fi and unplug Ethernet on your computer.

02

Send a message

Open the app, make sure the Fikra model is loaded, and ask “Who are you?”.

03

See the reply

If it answers while disconnected, the model is running on your device. That is the whole point.

If it does not reply, check that you loaded the local model, not an online or cloud model.

Troubleshooting / quick fixes

If something goes wrong.

The app says the model is not supported.

Update the app to the latest version. Fikra Model 2 uses a recent Qwen3.5 architecture; older app builds may not load it. If it still fails, try Model 1 – 2B or LM Studio on a computer.

The app crashes or says out of memory.

Close other apps, set the context length to 2048 or 4096, and try again. A 4B model needs memory headroom. On a phone with 4 GB RAM, use the online demo instead.

It is very slow.

That is normal on a CPU. Expect a few words per second on a phone. Lower the context length, close other apps, or use a computer with a GPU for faster replies.

The model file will not import.

Check that the download finished and the file ends in .gguf. Do not unzip it. Import it from the app's Models screen, or restart the app and try again.

Does it need internet?

Only for the one-time download. After the app and model are installed, turn on Airplane Mode and it still works.

Is my data private?

Yes. The model runs on your device and your prompts and replies stay there. The app may check for updates, but the conversation is not sent to a server.

Can I use it commercially?

Fikra Model 2 is Apache 2.0. Fikra Model 1 uses the Zabibu Technika License 1.1; review it before commercial use.

My phone has 4 GB RAM. Can I run it?

Not comfortably. A 4B model needs more headroom. Use the online chat demo or run Fikra on a computer.

Optional / for developers

Prefer the terminal?

Show llama.cpp and Ollama commands

You do not need any of this for the guide above. These commands are for people who already use a terminal.

llama.cpp

# 1. Download the model (macOS / Linux)
curl -L -o Fikra-Model-2-4B-Q4_K_M.gguf \
  "https://huggingface.co/zabibutechnika/Fikra-Model-2-4B-GGUF/resolve/main/Fikra-Model-2-4B-Q4_K_M.gguf?download=true"

# 2. Chat
llama-cli -m Fikra-Model-2-4B-Q4_K_M.gguf -p "Who are you?" -c 4096

Ollama

# Save this as Modelfile
FROM ./Fikra-Model-2-4B-Q4_K_M.gguf
PARAMETER num_ctx 4096

# Create and run
ollama create fikra -f Modelfile
ollama run fikra
